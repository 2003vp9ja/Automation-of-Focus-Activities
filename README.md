# Automation of Focus Activities

## Project Overview

An Android application designed to simplify college event management by providing students with access to event information, registration, notifications, profiles, and previous event records.

## Features

* Splash screen
* Login and Sign Up screens
* Home dashboard
* Event search
* Event registration
* Student profile
* Calendar screen
* Event notifications
* Previous event records
* PDF certificate generation

## Technologies Used

* Kotlin
* Android Studio
* Jetpack Compose
* Material 3
* Android SDK

## Project Purpose

The purpose of this project is to simplify college event management, reduce manual work, and help students access event information easily.
